# 网易MMO策划人才盘点（面试方案）

网易星火人力管培命题四的面试演示原型。所有人员、项目、事件均为虚构模拟数据，不代表网易内部信息。

## 演示功能

- 决策总览：人才结构、待确认信号、证据时效和行动进度
- 人才画像：按策划岗位查看六项能力、发展意愿与证据时间线
- 连续信号：记录关键项目事件，由主管确认后进入证据档案
- 新项目组队：按岗位和项目阶段调整匹配情境，检查证据和老项目接续
- 诊断报告：实时汇总建议，打印或保存 PDF
- 画像配置与导入：调整维度权重、导入人员/证据 CSV、导出当前数据
- DeepSeek 可选辅助：纪要信号抽取、人才证据审计与追问、讨论提纲；不自动评分

网页是纯静态站点，数据保存在访问者的浏览器 `localStorage` 中；不同访问者之间不会共享数据。DeepSeek Key 仅保留在当前页面内存，不写入仓库或浏览器存储。请求显式关闭思考模式，并显示 HTTP 状态、API 错误或停止原因。由于 GitHub Pages 静态网页直连第三方 API 可能受到跨域、网络或密钥暴露风险，生产环境应使用服务端代理；现场演示可使用明确标注的“本地模拟审计”兜底。

十一页网页版汇报：[打开演示文稿](presentation/index.html)，计划讲述约 15.5 分钟，支持左右键翻页、总览和演讲者视图。另有一个[浏览器可编辑版本](presentation/editable.html)：点击右上角“开始编辑文字”，修改后可导出新的单文件 HTML。采用简洁网格排版与网易红启发式配色；不使用封面插画。演示数据和岗位画像均为面试方案，不代表网易内部事实。红色 `#D12020` 是本原型的近似视觉选择，不宣称为官方品牌规范色值。

附加提交材料包括 [演讲稿与系统演示话术](演讲稿.md)、[演示文稿编辑说明](presentation/编辑说明.md)、[AI 交互记录](AI交互记录.html)、[答辩题库](答辩题库.md)、[作业说明与入口](作业说明与入口.md) 和 [提交清单](提交清单.md)。

## 本地预览

需通过本地 HTTP 服务打开，避免浏览器阻止 JavaScript 模块读取：

```powershell
node server.mjs
```

然后打开 `http://localhost:4173/`。

## GitHub Pages

仓库包含 `.github/workflows/deploy-pages.yml`。Pages 发布源选择 **GitHub Actions** 后，推送到 `main` 会同步发布系统首页及 `/presentation/` 网页汇报。

## CSV 模板

进入“画像配置与导入”页面下载人员与证据模板。上传时先校验列名、人员 ID、能力等级和日期；错误行会显示原因。建议先导入人员，再导入引用这些人员 ID 的证据。

页面同时提供三份完全虚构的测试材料：日常关键事件 CSV、季度盘点纪要 CSV，以及对应的原始季度会议纪要。可用它们演示“原始沟通—人工抽取—主管确认—进入人才判断”的过程。

“连续信号”页面支持上传 TXT、Markdown 和 Word `.docx` 纪要。TXT/Markdown 与 DOCX 的文字提取均在浏览器完成；本地规则可直接生成候选能力信号。若用户主动输入 DeepSeek Key 并点击深度解析，系统才会把提取后的纪要文字发送给 DeepSeek。候选项必须经人工编辑和确认，写入后状态仍为“待确认”，不会自动修改能力等级。
