# 演示文稿编辑说明

## 最简单的修改方式

1. 用浏览器打开 `presentation/editable.html`。
2. 点击右上角“开始编辑文字”。
3. 直接点击标题、正文或列表进行修改。
4. 修改完成后点击“导出当前 HTML”。浏览器会下载 `网易MMO策划人才盘点_修改版.html`。

这个版本适合现场前快速改字。它不会自动修改仓库中的源文件，所以改完一定要导出保存。图片与脚本使用相对路径；如需离线移动文件，请让导出的 HTML 与原来的 `assets`、`images` 文件夹保持相同的相对位置。

## 修改结构或图片

- 页面内容源文件：`presentation/slides.html`
- 演讲者备注：`presentation/notes.js`
- 生成脚本：`presentation/build.mjs`
- 图片目录：`presentation/images/`

修改后在仓库根目录运行：

```powershell
node presentation/build.mjs
```

脚本会同时生成普通演示版 `presentation/index.html` 和浏览器可编辑版 `presentation/editable.html`。

## 演示快捷键

- 左右方向键：上一页／下一页
- `O`：幻灯片总览
- `P`：演讲者视图
- `F`：全屏
